# 09 — Content Pipeline

> Content is the lifeblood of Nexus Academy. This document covers how content is
> authored by hand, generated by Atlas, validated for educational accuracy, cached
> for offline play, and distributed to devices including satellite speakers. The
> pipeline ensures every player always has years of fresh, personalized, educationally
> valid content ready to play — with or without a network connection.

---

## Content Types

| Type | Format | Source | Size per Quest |
|------|--------|--------|---------------|
| **Quest definitions** | JSON | Handcrafted + Atlas-generated | 5-50 KB |
| **Companion dialogue** | JSON + TTS audio (OGG) | Atlas-generated, human-reviewed | 100-500 KB audio |
| **3D assets** | glTF 2.0 | Procedural + handcrafted | 50-500 KB per object |
| **Textures** | WebP/PNG | Procedural + handcrafted | 10-200 KB each |
| **Sound effects** | OGG Vorbis 44.1kHz | Pre-recorded library | 10-100 KB each |
| **Music** | OGG Vorbis 128kbps | Composed + layered | 2-5 MB per biome track |
| **Curriculum maps** | JSON | Handcrafted | 10-50 KB per standard |

## Quest Definition Format

Every quest follows a structured JSON format:

```json
{
  "id": "quest-crystal-bridge-001",
  "title": "The Crystal Bridge",
  "biome": "crystal_caverns",
  "mastery_tier": "discovery",
  "estimated_minutes": 15,
  "skills": {
    "required": ["math.arithmetic.addition", "math.geometry.shapes"],
    "taught": ["math.geometry.angles", "physics.forces.balance"],
    "reviewed": ["math.arithmetic.multiplication"]
  },
  "difficulty": {
    "base": 0.4,
    "adaptive_range": [0.3, 0.6]
  },
  "steps": [
    {
      "type": "narrative",
      "companion_text": "Look at this cavern! There's a gap we need to cross.",
      "audio_id": "quest-crystal-bridge-001-s1",
      "voice_mode_text": "We're in a huge crystal cavern. I can see a gap ahead — about 5 meters wide. The crystals on the other side are glowing purple."
    },
    {
      "type": "challenge",
      "prompt": "The gap is 5 meters wide. Each crystal plank is 1.5 meters. Minimum planks?",
      "answer_type": "number",
      "correct": 4,
      "tolerance": 0,
      "hints": [
        "How many 1.5s fit in 5?",
        "1.5 + 1.5 + 1.5 = 4.5. That's not quite 5…"
      ],
      "skills_tested": ["math.arithmetic.division", "math.number_sense.estimation"],
      "wrong_answer_responses": {
        "3": "3 planks = 4.5 meters. The gap is 5 meters. We'd fall short!",
        "5": "5 would work but that's more than we need. Can we do it with fewer?"
      }
    },
    {
      "type": "build",
      "description": "Place crystal planks to build the bridge",
      "physics_enabled": true,
      "success_condition": "bridge_stable AND player_crossed",
      "failure_response": "The bridge wobbled! I think we need to support the middle."
    }
  ],
  "rewards": {
    "items": ["crystal_compass"],
    "biome_unlock": null,
    "story_fragment": null,
    "companion_dialogue": "We make a great team! That bridge is solid."
  },
  "voice_mode": {
    "compatible": true,
    "audio_description": "The crystal cavern echoes with dripping water and faint chimes."
  },
  "metadata": {
    "generated_by": "atlas",
    "generated_at": "2025-07-15T22:30:00Z",
    "validated": true,
    "validated_by": "auto",
    "version": 1
  }
}
```

### Key Design Rules for Quests

1. **Every quest must have `skills.taught`** — if it doesn't teach something, it doesn't exist
2. **Every challenge must have hints** — minimum 2 hints per challenge step
3. **Wrong answer responses should be specific** — not generic "try again" messages
4. **Voice mode compatibility** — every quest must specify if it works audio-only
5. **Physics-enabled steps** must use real physics — no faking outcomes
6. **Rewards must be meaningful** — connected to world expansion, not arbitrary tokens

## Content Sources

### Handcrafted Content (Human-Authored)

The game ships with **4,017 handcrafted quests** across all biomes and the first two
mastery tiers, providing an estimated **8,273+ hours of unique gameplay** per player —
over 10× more content than any single player needs.

| Use Case | Volume | Quality |
|----------|--------|---------|
| Foundation tier quests | 37 across 3 biomes (workshop/forest/caverns) | Highest — first play experience |
| Discovery tier quests | ~1,000 across all 27 biomes (~37 per biome) | High — core content |
| Calibration zone quests | ~50 quests | Highest — must accurately assess every subject |
| Story quests (The Founders arc) | ~100 quests | Highest — narrative quality matters |
| Tier transition quests | ~20 per transition | High — defines the tier shift experience |
| Total handcrafted | **4,017 quests** | Human-authored, educationally validated |

### Content Hours Model

| Metric | Value |
|--------|-------|
| Total handcrafted quests | 4,017 |
| Average quest duration | ~15-30 minutes |
| Estimated total content hours | 8,273+ |
| Hours a daily player (1hr/day, age 2-18) accumulates | ~5,840 |
| Content-to-need ratio | >10× — no player exhausts content |

The curriculum covers 14 subjects and ~11,400 discrete skills (see
[CURRICULUM_SKILL_COUNTS.md](CURRICULUM_SKILL_COUNTS.md)). With Atlas generating
additional personalized content between sessions, the effective content library is
unlimited.

### Atlas-Generated Content

| Use Case | Volume | Quality Control |
|----------|--------|----------------|
| Gap remediation quests | 5-10 per player per week | Auto-validated + spot-checked |
| Advancement quests | 3-5 per player per week | Auto-validated |
| Impossible challenges | 1-2 per player per 2 weeks | Human-reviewed (educational accuracy critical) |
| Spaced repetition events | 2-5 per player per session | Auto-validated (variation on proven templates) |
| Interest-driven exploration | As needed | Auto-validated + player feedback signals |

Atlas generates ~20-30 quests per active player per week.

### Player-Created Content (Creator Tier)

Creator-tier players can create quests for younger players. Pipeline:

1. Player designs quest using creation tools
2. Atlas validates educational accuracy and safety
3. Content reviewed (auto + human for first submissions)
4. If approved, enters the content pool for other players
5. Creator receives "Founder" credit (visible to them, anonymous to recipients)

## Validation Pipeline

Every piece of content passes through validation before reaching a player.

### Auto-Validation

```
Content Validator
├── Educational Accuracy
│   ├── Math: answers are numerically correct
│   ├── Chemistry: equations balance, formulas are real
│   ├── Physics: outcomes match real physics
│   ├── Biology: facts are accurate
│   └── History: events and dates are correct
│
├── Age Appropriateness
│   ├── Vocabulary matches tier reading level
│   ├── Concepts match tier difficulty range
│   ├── No content inappropriate for the age range
│   └── Violence/conflict within guidelines (no gore, no real weapons)
│
├── Game Design Quality
│   ├── Has clear hook (why should the player care?)
│   ├── Has meaningful reward
│   ├── Challenge difficulty in range
│   ├── Hints are progressively helpful
│   └── Failure responses are gentle and educational
│
├── Technical Validity
│   ├── JSON schema validates
│   ├── Referenced assets exist
│   ├── TTS audio renders correctly
│   └── Physics simulations don't crash
│
└── Safety
    ├── No PII in content
    ├── No inappropriate themes
    ├── COPPA compliance check
    └── No external links or references
```

### Human Review

Required for:
- All story/narrative quests (The Founders arc)
- Impossible challenges (educational accuracy is critical)
- First 10 quests from any new Atlas model version
- Player-created content (first submissions)
- Any content flagged by auto-validation as uncertain

## Caching Strategy

### Per-Player Cache

Each player has a content cache sized for years of play:

| Cache Layer | Size | Contents | Location |
|-------------|------|----------|----------|
| Active session | 50 MB | Current quests, nearby biome chunks, active audio | Client memory |
| Local cache | 500 MB | 3-4 years of pre-generated quests + audio | IndexedDB / device storage |
| Server cache | 2 GB | Full content library per player | Game server SQLite |

### Cache Refresh

```
Daily (when connected):
  1. Sync progress data → server
  2. Pull new quests from latest Atlas batch
  3. Pull updated spaced repetition schedule
  4. Pre-render any needed audio
  5. Update local cache

Weekly (background):
  1. Full cache refresh from server
  2. Prune completed/expired quests
  3. Verify asset integrity
  4. Update curriculum alignment data
```

### Offline Duration Support

| Offline Duration | Player Impact |
|-----------------|---------------|
| Hours | None — active session cache covers this |
| Days | None — local cache has weeks of content |
| Weeks | None — local cache has months of content |
| Months | Possible content thinning — Atlas hasn't refreshed cache |
| 1+ Year | May exhaust pre-cached content — but handcrafted seed content is always available |

## Satellite Distribution

Satellite speakers (Hermes — see [12-VOICE_GAMEPLAY.md](12-VOICE_GAMEPLAY.md)) need
voice-only content pushed to them.

### Satellite Content Package

```json
{
  "profile_id": "emma-001",
  "package_version": "2025-07-15",
  "quests": [
    {
      "id": "voice-counting-garden-042",
      "audio_clips": [
        {"id": "intro", "file": "042-intro.ogg", "duration_ms": 8500},
        {"id": "prompt1", "file": "042-p1.ogg", "duration_ms": 3200},
        {"id": "correct1", "file": "042-c1.ogg", "duration_ms": 2100},
        {"id": "wrong1", "file": "042-w1.ogg", "duration_ms": 4300},
        {"id": "hint1", "file": "042-h1.ogg", "duration_ms": 3800}
      ],
      "sfx": ["birds", "seed_plant", "water", "growth", "celebration"],
      "ambient": "garden",
      "expected_answers": {
        "prompt1": {"correct": ["five", "5"], "fuzzy": true}
      }
    }
  ],
  "total_size_mb": 45
}
```

### Satellite Sync Protocol

```
1. Satellite connects to game server on LAN
2. Requests content package for registered profiles
3. Server sends delta (only new/changed content since last sync)
4. Satellite caches locally (SD card on Pi, flash on ESP32)
5. Satellite reports last-sync timestamp
6. Progress from satellite sessions syncs back to server
```

## Procedural Quest Engine

Beyond handcrafted and Atlas-generated quests, the **Procedural Quest Engine** generates
quests from templates at runtime, providing infinite variety without requiring Atlas
connectivity.

### How It Works

The engine uses **51 quest templates** across **23 game mechanics**, combined with an
**anti-repetition tracker** that ensures no player encounters the same quest pattern
too frequently.

```
Procedural Quest Generation:
  1. Select template based on player's current skills and biome
  2. Parameterize with context (numbers, materials, characters, setting)
  3. Anti-repetition check: has the player seen this template recently?
     → If yes, select alternate template or modify parameters significantly
  4. Difficulty calibration via Bayesian IRT estimates
  5. Generate companion dialogue hooks
  6. Validate educational accuracy (built-in rules engine)
  7. Serve to player as a natural world event
```

### Template Example

```json
{
  "template_id": "bridge-construction",
  "mechanic": "building",
  "parameters": {
    "gap_width": {"min": 3, "max": 50, "unit": "meters", "scales_with": "math.geometry"},
    "material": {"options": ["wood", "stone", "metal", "crystal"], "scales_with": "tier"},
    "load_requirement": {"min": 50, "max": 10000, "unit": "kg", "scales_with": "physics.forces"},
    "environmental_factor": ["wind", "water_current", "earthquake", "none"]
  },
  "skills_tested": ["math.geometry.angles", "physics.forces.balance", "engineering.structures"],
  "anti_repetition_cooldown_days": 14
}
```

### Anti-Repetition Tracker

The tracker maintains a sliding window of recent quest patterns per player:

- **Template cooldown** — Each template has a minimum interval before reuse (7-30 days)
- **Mechanic variety** — No more than 2 quests of the same mechanic type per session
- **Biome rotation** — Encourages exploration across biomes rather than camping
- **Parameter variation** — Even when a template repeats, numbers, context, and characters differ significantly

This system ensures that even in standalone mode (no Atlas), the game never runs out
of fresh, educationally valid content.

## Content Metrics

Atlas tracks content performance:

| Metric | Purpose |
|--------|---------|
| Completion rate | Do players finish this quest? |
| Time to complete | Is it appropriately long? |
| Hint usage rate | Is it too hard? Too easy? |
| Replay value | Do players revisit voluntarily? |
| Skip rate | Do players avoid this quest? |
| Learning efficacy | Does completing this quest improve the target skill? |
| Engagement score | Are players in flow state during this quest? |

Low-performing content is flagged for revision. High-performing content is used as
templates for future generation.
