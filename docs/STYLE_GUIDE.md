# Nexus Academy — Style Guide

> This document defines the visual identity of Nexus Academy. Every screen,
> every element, every color must follow this guide. If it looks like "AI slop,"
> generic dark mode, or a SaaS dashboard — it's wrong.

---

## The Core Identity

**Nexus Academy is a place you ENTER — not an app you open.**

Every visual choice serves one question: *"Does this feel like stepping into
a world that was built for me?"*

### What Nexus IS
- Warm, alive, inviting
- Magical but grounded
- A place you want to be
- Feels handcrafted, not generated
- Emotionally resonant at every age

### What Nexus IS NOT
- Dark mode Dracula (that's a code editor)
- Material Design (that's a productivity app)
- Flat/corporate (that's a SaaS dashboard)
- Neon/cyberpunk (that's for adults)
- Generic, soulless, templated

## The Gateway (Title Screen)

### The Portal

The first experience:

1. Dark screen. Silence.
2. A single point of Frost blue (#22d3ee) light appears at center.
3. It expands into swirling ribbons of Frost → Aurora (#a78bfa), like
   northern lights compressed into a doorway.
4. Through the portal: a glimpse of warmth — golden light, soft shapes.
5. The title "Nexus Academy" forms from light particles drifting from
   the portal. Not text slapped on a background — light becoming words.
6. Below: *"Step inside."*

### The Nexus Voice

As the portal opens, a voice speaks:

> *"Welcome to the Nexus. Everything you need to know is already inside
> you. We're just going to help you find it."*

**The Nexus Voice is:**
- Androgynous / beyond gender — processed to feel more than human
- Futuristic but warm — confident, knowing, not cold
- Slight reverb + subtle harmonics — like it's coming from the world itself
- NOT robotic, NOT monotone, NOT aggressive

**The Nexus Voice speaks rarely (20 times in the entire game):**
- First launch: Full welcome
- Returning: *"Welcome back."*
- After long absence: *"It's been a while. The Nexus has been waiting."*
- Tier transitions: *"You've grown. The world grows with you."*
- Major discoveries: *"You're beginning to see."*
- Nexus Core arrival: *"You made it. You always could."*

The companion is personal (your friend). The Nexus Voice is cosmic (the
world itself). Two different relationships.

### Profile Creation

After stepping through the portal:
- Portal dissolves into the profile creation screen
- Background: warm gradient, NOT dark
- Foundation default: sunrise peach (#FFDAB9) → sky blue (#87CEEB)
- Large, friendly text: *"Who are you?"*
- Name input with warm styling
- Companion picker: colorful, animated, personality previews
- Age range picker (for calibration starting point)
- Big warm "Enter the Nexus" button

### After Profile: Arrival

The profile screen fades and you're IN the world. Your companion faces
you, eye level:

> *"Hi! I've been waiting for you. Welcome to the Nexus."*

## Interest-Adaptive UI

The UI background adapts to the player's detected interests. The Interest
Tracking system provides weights — the UI blends themes proportionally.

| Interest | Background Treatment |
|----------|---------------------|
| Nature | Soft greens, dappled light, leaf particle hints |
| Space | Deep indigo, distant stars, subtle nebula wisps |
| Technology | Dark surface, faint green terminal glow, circuit trace lines |
| Art | Watercolor wash gradients, paint splatter accents at edges |
| Music | Sound wave patterns in background, warm concert hall gold |
| Building | Blueprint grid overlay, copper schematic line traces |
| Ocean | Deep blue gradients, gentle caustic light patterns |
| Animals | Warm earth tones, subtle paw print / feather patterns |
| Sparkly/Crystal | Amethyst base, floating diamond light particles |

**Blending:** If a player loves nature AND space, they get a forest with
stars visible through the canopy. If they love tech AND music, they get
a sound-wave visualizer with circuit-board aesthetics.

The UI should feel like the world is seeping into the menus — not two
separate experiences.

## Component Styling

### Buttons

| Type | Style |
|------|-------|
| Primary (CTA) | Frost→Aurora gradient, dark text, rounded corners (0.5rem), min 44×44dp |
| Secondary | Transparent, Frost border, Frost text |
| Destructive | Warm coral background, dark text |
| Foundation | EXTRA large (80×80dp min), bright, bouncy hover |

### Input Fields

- Border: 2px `rgba(255,255,255,0.15)`, rounds to Frost on focus
- Background: `rgba(255,255,255,0.05)` (subtle, not invisible)
- Text: warm white `#F5F0E8`
- Placeholder: slate `#94A3B8`
- Error state: warm coral border + message below

### Cards (profile cards, quest cards)

- Background: `rgba(255,255,255,0.05)` with subtle border
- Hover: Frost border glow, slight background brightening
- Active/selected: Aurora border with shadow glow
- Rounded corners: 0.75rem
- Padding: generous (1rem+)

### Speech Bubbles (companion)

- Background: rgba(26, 27, 46, 0.85) — dark but not black
- Border: 1px Aurora with subtle glow
- Arrow pointing toward companion orb
- Text: warm white, Nunito Medium
- Speaker name in Aurora color

### Captions

- Background: rgba(0, 0, 0, 0.75) — readable over any scene
- Text: warm white
- SFX captions: Frost color, italic, e.g., *"[Crystal chime]"*
- Speaker label: Aurora color, bold

## Animation & Motion

### Foundation Tier
- Bouncy, exaggerated (squash and stretch)
- Gentle pulsing on interactive elements
- Sparkle particles on discovery
- Everything feels alive and responsive

### Discovery+
- Smooth, natural transitions
- Subtle hover effects
- Particle effects for atmosphere (unless reduced motion)

### All Tiers
- Respect `prefers-reduced-motion` — instant transitions, no particles
- Loading: Frost/Aurora gradient spinner (not a generic circle)
- Page transitions: fade through warm color, not black

### NEVER
- Harsh flashing
- Screen shake (unless preference allows)
- Sudden appearance/disappearance (always fade or slide)
- Generic CSS spinner

## The Companion (3D)

### Appearance in World
- Floating orb/entity near player
- Frost core (#22d3ee) with Aurora (#a78bfa) outer glow
- Gentle bobbing motion (sine wave, 0.5Hz)
- Point light emanating from them (warm, subtle)
- Faces the player when speaking
- Scales with tier: simpler glow for Foundation, more detailed for Creator

### In UI
- Small avatar icon in dialogue bubbles
- Uses the emoji/avatar chosen at profile creation
- Always has a warm glow ring around their icon

## Accessibility Overrides

All style choices have accessible alternatives:

| Feature | Override |
|---------|---------|
| Gradients | Solid colors in high-contrast mode |
| Transparency | Opaque backgrounds for readability |
| Animations | Instant transitions when reduced-motion |
| Fonts | OpenDyslexic / Atkinson Hyperlegible available |
| Colors | Color-blind filters + shape identifiers |
| Text size | 50-200% scaling without layout breaking |
