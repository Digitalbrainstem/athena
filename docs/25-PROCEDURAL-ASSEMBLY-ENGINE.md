# 25 — Procedural Assembly Engine (Voice DNA + Model DNA)

> Core technology for Nexus Academy: generate infinite content on ANY device
> from compact building blocks. No GPU, no LLM, no internet required at runtime.
> Written in C, compiled to WASM for universal deployment.

---

## The Problem

Nexus Academy has 9,000+ hours of gameplay across 27+ biomes, 13,600 NPCs,
6 companions, and thousands of quests. Pre-generating all content is impossible:

| Content Type | Unique Items Needed | Pre-gen Storage |
|---|---|---|
| Companion voice lines | 100K-500K per companion | 50-250 GB each |
| NPC voice lines | 5-10M total | 500 TB+ |
| 3D NPC models | 13,600 unique | 68 GB |
| NPC animations | 50K+ unique combos | 250 GB |
| **Total pre-gen** | | **Impossible** |

## The Solution: DNA Assembly

Instead of generating complete assets, we generate **building blocks (DNA)**
and assemble them at runtime using deterministic algorithms. No AI needed
at runtime — pure math, runs on any CPU.

```
OFFLINE (one-time, using AI on GPU):
  AI generates high-quality building blocks → "DNA library"

RUNTIME (any device, any CPU):
  Text/parameters → DNA assembly algorithm → final asset
  No GPU. No AI. No internet. Pure deterministic math.
```

## Part 1: Voice DNA Engine

### Concept

Every voice is decomposed into reusable phonetic units generated by
Chatterbox TTS at maximum quality. Runtime assembly stitches units
together with prosody curves and crossfade smoothing.

### Voice DNA Library (generated once per voice)

| Component | Count | Description | Size |
|---|---|---|---|
| **Diphones** | ~2,500 | Every phoneme-to-phoneme transition ("ah→b", "s→t") | 15 MB |
| **Triphones** | ~5,000 | Three-phoneme sequences for natural context | 15 MB |
| **Emotional variants** | ×6 emotions | Each diphone at: neutral, excited, gentle, urgent, calm, whispered | ×6 |
| **Pitch variants** | ×3 | Low, mid, high pitch for each unit | ×3 |
| **Prosody curves** | ~200 | Rhythm/timing patterns per sentence type | 50 KB |
| **Breath/pause** | ~50 | Inhale, exhale, "hmm", "oh", silence variants | 500 KB |
| **Personality sounds** | ~30 | Laughs, gasps, sighs, unique character sounds | 300 KB |
| **Total per voice** | | | **~35-50 MB** |

### Generating the DNA (offline, Chatterbox on GPU)

```python
# For each voice reference (e.g., philippa.wav for Fox):
for diphone in ALL_ENGLISH_DIPHONES:        # ~2,500
    for emotion in EMOTIONS:                 # 6
        for pitch in [low, mid, high]:       # 3
            text = carrier_sentence(diphone) # "Say 'aba' please"
            exag = EMOTION_MAP[emotion]
            wav = chatterbox.generate(text, ref=voice_ref, exaggeration=exag)
            segment = extract_diphone(wav, diphone)
            save_to_dna(voice_id, diphone, emotion, pitch, segment)

# Total generations per voice: 2,500 × 6 × 3 = 45,000 segments
# At 3/min on 4060: ~250 hours per voice
# At 40/min with batching optimization: ~19 hours per voice
# 6 companions: ~114 hours (~5 days)
# 35 NPC voice profiles: ~28 days
```

### Runtime Assembly (C → WASM, any device)

```c
// voice_dna.h — Nexus Academy Voice DNA Engine
// Compiles to: WASM (browser), native (console/PC), ARM (phone/tablet)

typedef struct {
    int16_t* samples;      // PCM audio data
    uint32_t length;       // sample count
    float    pitch_hz;     // base pitch
    float    energy;       // RMS energy
} VoiceUnit;

typedef struct {
    VoiceUnit** diphones;  // [phoneme_a][phoneme_b] → unit
    VoiceUnit** triphones; // [a][b][c] → unit (preferred if available)
    float*      prosody;   // pitch curve for current sentence
    int         emotion;   // current emotion index
    int         pitch;     // current pitch variant
} VoiceDNA;

// Core API
VoiceDNA*  voice_dna_load(const char* path);           // load ~40MB DNA file
void       voice_dna_free(VoiceDNA* dna);
int        voice_dna_set_emotion(VoiceDNA* dna, int emotion, float intensity);
int        voice_dna_synthesize(VoiceDNA* dna, const char* text,
                                 int16_t* out_buffer, uint32_t* out_length);

// Internal pipeline:
// 1. text_to_phonemes(text) → phoneme sequence
// 2. select_units(dna, phonemes, emotion) → best matching units
// 3. apply_prosody(units, sentence_type) → pitch/timing curves
// 4. crossfade_stitch(units) → smooth audio
// 5. apply_emotion_envelope(audio, emotion, intensity) → final output
```

### Unit Selection Algorithm

Based on SelectTTS (2024) and UnitNet research:

```
For each phoneme transition needed:
  1. Look up candidate units from DNA library
  2. Score each candidate:
     - target_cost: how well does this unit match the desired phoneme?
     - join_cost: how smooth is the transition from the previous unit?
     - prosody_cost: does the pitch/duration match the prosody curve?
     - emotion_cost: does the energy/pitch match the target emotion?
  3. Select unit with lowest total cost
  4. Crossfade with previous unit (5-10ms overlap, raised cosine window)
```

### Quality Assessment

| System | Quality (MOS) | Size | Device |
|---|---|---|---|
| Chatterbox (neural) | 4.3/5 | 3 GB + GPU | PC only |
| Piper (neural, small) | 3.2/5 | 20 MB + CPU | Any |
| **Voice DNA (ours)** | **3.8-4.1/5 est** | **40 MB + CPU** | **Any** |
| Raw concatenation | 2.5/5 | 40 MB + CPU | Any |

Voice DNA should achieve 3.8-4.1 MOS because:
- Units are generated by Chatterbox (4.3 quality source)
- Neural-guided unit selection (SelectTTS-inspired)
- Prosody curves maintain natural rhythm
- Crossfade smoothing eliminates boundary artifacts
- In-game context (music + SFX) masks remaining artifacts

## Part 2: Model DNA Engine

### Concept

Instead of 13,600 unique 3D models, generate **modular parts** and assemble
unique characters/objects at runtime from parameters. No LLM needed —
the assembly is deterministic from a seed/parameter set.

### Model DNA Library

| Component | Parts | Description |
|---|---|---|
| **Body bases** | 20 | Child, teen, adult × body types × genders |
| **Heads** | 40 | Face shapes, jaw lines, proportions |
| **Hair** | 60 | Styles, lengths, textures |
| **Eyes** | 30 | Shapes, colors, expressions |
| **Outfits (tops)** | 80 | Shirts, robes, armor, aprons |
| **Outfits (bottoms)** | 60 | Pants, skirts, shorts |
| **Accessories** | 100 | Hats, glasses, tools, bags, jewelry |
| **Shoes** | 30 | Boots, sandals, bare feet |
| **Skin textures** | 20 | Diverse skin tones + alien variants |
| **Total parts** | ~440 | |
| **Unique combinations** | **440! combos** | Effectively infinite |
| **Storage** | **~500 MB** | vs 68 GB for pre-gen |

### NPC Assembly (runtime, any CPU)

```c
// model_dna.h — Nexus Academy Model DNA Engine

typedef struct {
    uint16_t body_base;     // 0-19
    uint16_t head;          // 0-39
    uint16_t hair;          // 0-59
    uint16_t eyes;          // 0-29
    uint16_t outfit_top;    // 0-79
    uint16_t outfit_bottom; // 0-59
    uint16_t accessory[4];  // up to 4 accessories
    uint16_t shoes;         // 0-29
    uint16_t skin_texture;  // 0-19
    float    height_scale;  // 0.8 - 1.2
    float    weight_scale;  // 0.8 - 1.2
    uint32_t seed;          // deterministic randomization
} NPCParams;

// From params → assembled GLB mesh ready for rendering
// Same params ALWAYS produce same NPC (deterministic)
ModelDNA*  model_dna_load(const char* parts_dir);
Mesh*      model_dna_assemble_npc(ModelDNA* dna, NPCParams* params);
void       model_dna_free(ModelDNA* dna);

// Key: NO AI/LLM NEEDED at runtime
// NPC params come from:
//   - Pre-generated content files (JSON)
//   - Deterministic seed-based generation
//   - Or Atlas-generated between sessions (optional)
```

### Vegetation/Object Assembly

Same principle for trees, buildings, furniture:

```
Tree DNA:
  - 10 trunk types × 15 branch patterns × 20 leaf types × 8 seasons
  - = 24,000 unique trees from ~50 parts (~100 MB)

Building DNA:
  - 8 foundations × 12 wall types × 10 roofs × 15 door/window sets
  - = 14,400 unique buildings from ~45 parts (~80 MB)
```

### Animation DNA

Animations decompose the same way:

| Component | Parts | Description |
|---|---|---|
| **Walk cycles** | 10 | Different gaits per personality |
| **Idle animations** | 20 | Fidgets, shifts, looks around |
| **Gesture library** | 40 | Point, wave, nod, shrug, clap |
| **Emotion overlays** | 15 | Happy, sad, angry, scared modifiers |
| **Lip sync phonemes** | 30 | Mouth shapes per phoneme |
| **Blend trees** | 50 | Smooth transitions between states |

Runtime blends these together: walk_cycle + emotion_overlay + gesture = unique animation.
Same CPU-only math, no AI needed.

## Part 3: Content Scripts (No LLM Needed)

The game needs TEXT for Voice DNA to speak. Without Atlas/LLM:

### Template System

```json
{
  "companion_greeting": {
    "templates": [
      "Good {time_of_day}! Ready to explore {biome_name}?",
      "I love {biome_name}! Did you know {biome_fact}?",
      "{emotion_exclaim} Look at {nearby_object}!"
    ],
    "variables": {
      "time_of_day": ["morning", "afternoon", "evening"],
      "emotion_exclaim": ["Wow!", "Oh!", "Amazing!", "Cool!"],
      "biome_fact": "content/facts/{biome_id}.json"
    }
  }
}
```

- **~5,000 templates** cover all dialogue situations
- Variables fill in context (biome, time, nearby objects, player progress)
- **Markov chain** or **grammar-based** text generation for variety
- All deterministic, all CPU, no LLM
- Templates stored as JSON: ~2 MB total

### With Atlas (optional enhancement)

If Atlas IS available (connected to home server):
- Atlas generates BETTER text (more natural, more varied)
- Pushed to device between sessions
- Game works without it, but Atlas makes dialogue richer

## Part 4: Alien Languages

### Concept

12 alien civilizations each have unique languages built from invented
phoneme sets + DSP effects. Same Voice DNA engine, different sound palette.
No AI needed at runtime — pure DSP math.

### Per-Civilization Sound Design

| Civilization | Sound Character | DSP Chain |
|---|---|---|
| Crystal World | Crystalline, harmonic overtones | reverb + harmonic doubling + shimmer |
| Ocean World | Bubbly, flowing, liquid | underwater filter + gurgle layer + flow |
| Nebula Beings | Electromagnetic, ethereal | ring modulation + chorus + multi-tone |
| Ring World | Mechanical, precise, metallic | formant crush + metallic resonance |
| Ice World | Breathy, whispery, crackling | heavy breath + ice crackle + whisper |
| Jungle World | Rhythmic, tonal, percussive | pitch bends + click consonants + drums |
| Desert World | Guttural, resonant, deep | throat singing harmonics + sand rasp |
| Volcanic World | Rumbling, explosive, hot | distortion + sub-bass + hiss |
| Dying Galaxy | Slow, decaying, entropic | time stretch + bit crush + fade |
| Ancient Civ | Melodic, mathematical, precise | pure tones + frequency ratios |
| Hive Mind | Overlapping, collective, buzzing | multi-voice chorus + bee harmonics |
| Nomad Fleet | Radio-like, compressed, urgent | band-pass filter + static + compression |

### Generation (GPU, one-time)

Per civilization:
- Generate ~40 unique alien phonemes using Chatterbox with extreme settings
- ~120 segments (40 phonemes × 3 emotion levels)
- ~15 minutes per civilization on a 4090

12 civilizations × 15 min = **~3 hours total**

### Runtime (CPU, any device)

```c
// alien_voice.h — extends voice_dna.h

typedef struct {
    VoiceDNA*    base_dna;        // alien phoneme segments
    DSPChain*    civilization_fx;  // reverb + filters per civ
    Grammar*     language_rules;   // how phonemes combine
    float        speak_rate;       // base speaking speed
} AlienVoice;

// Generate alien speech from meaning (not text)
int alien_voice_speak(AlienVoice* voice, const char* meaning_tag,
                      int16_t* out_buffer, uint32_t* out_length);

// DSP effects are simple math — all run on CPU:
// - Ring modulation: sample * sin(freq * t)
// - Formant shift: frequency-domain scaling
// - Reverb: convolution with impulse response
// - Chorus: delayed copies with slight detuning
```

### Storage: ~15 MB per alien language, ~180 MB total for 12 civilizations

## Part 5: NPC Voice Multiplication

### From 6 base voices → 4,500+ unique NPCs

DSP modifications on the base Voice DNA create perceptually distinct voices:

| Parameter | Range | Steps | Effect |
|---|---|---|---|
| Pitch shift | -30% to +30% | 10 | Age/gender perception |
| Formant shift | -20% to +20% | 5 | Body size/throat shape |
| Speaking rate | 0.85× to 1.15× | 5 | Personality (rushed vs deliberate) |
| Resonance type | normal/nasal/breathy | 3 | Voice character |

6 bases × 10 × 5 × 5 × 3 = **4,500 unique NPC voices**

Each NPC stores just a parameter set (6 bytes):
```c
typedef struct {
    uint8_t base_voice;    // 0-5
    int8_t  pitch_shift;   // -30 to +30
    int8_t  formant_shift; // -20 to +20
    uint8_t speak_rate;    // 85-115 (×0.01)
    uint8_t resonance;     // 0=normal, 1=nasal, 2=breathy
    uint8_t reserved;
} NPCVoiceParams;  // 6 bytes per NPC
```

13,600 NPCs × 6 bytes = **81.6 KB** for all NPC voice assignments.
