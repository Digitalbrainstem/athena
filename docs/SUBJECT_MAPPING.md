# Subject → Game Mechanic Mapping

> Every subject, every age tier, mapped to gameplay that demands real knowledge.
> Nothing is a quiz. Everything is the world responding to what the player knows.

## Mathematics

### Counting & Number Sense (Little Learner, 2–5)

| Concept | Game Mechanic | Example |
|---------|--------------|---------|
| Counting 1–20 | Collecting items with companion | "I see butterflies! Count them with me — one… two… three!" |
| Counting to 100 | Inventory stacking | Coins auto-stack in groups of 10. "How many groups? How many left over?" |
| Number recognition | Door codes, treasure locks | Companion: "The door says 7! Can you find the 7 key?" |
| More/less/equal | Balance scales | Put apples on one side, oranges on the other. Which is more? |
| Place value | Coin exchange | 10 copper = 1 silver. "You have 23 copper. How many silver is that?" |
| Patterns | Path puzzles | Step on tiles in the right pattern: red, blue, red, blue, ___? |
| Sorting | Organizing collections | Sort gems by color, size, or shape to unlock treasure chest |
| Basic addition | Bridge building | "We need 5 planks. We have 3. How many more?" |

### Arithmetic (Explorer, 6–10)

| Concept | Game Mechanic | Example |
|---------|--------------|---------|
| Addition/subtraction | Resource management | "47 coins. The sword costs 23. How much left?" |
| Multiplication | Batch crafting | "Each potion needs 3 herbs. You need 7 potions. How many herbs total?" |
| Division | Fair splitting | "12 supplies, 4 villages. How many does each village get?" |
| Fractions | Recipe crafting | "Needs ¾ cup. You have ½ cup scoops. How many scoops?" |
| Decimals | Trading/currency | "Gold coins = 1.0, silver = 0.1, copper = 0.01. What's your total?" |
| Percentages | Shop discounts | "The merchant says 25% off. The shield was 80 gold. What's the price?" |
| Order of operations | Machine programming | "Set the machine: first multiply fuel × 3, then add 5 heat units." |
| Negative numbers | Temperature/depth | "The cave goes 5 levels below ground. You climb up 3. Where are you?" |

## Cross-Subject Integration

The real power of Nexus Academy is that subjects don't exist in isolation:

| Quest Example | Subjects Combined |
|--------------|-------------------|
| "Build a spaceship and navigate to the moon" | Physics (thrust), Chemistry (fuel), Math (trajectory), CS (autopilot) |
| "Cure the village plague" | Biology (pathogen), Chemistry (medicine), Economics (resource allocation), Ethics (triage) |
| "Build a hydroelectric dam" | Physics (energy), Engineering (structure), Ecology (environmental impact), Economics (cost-benefit) |
| "Decode the alien transmission" | Math (number theory), CS (signal processing), Language (pattern recognition), Physics (EM waves) |
| "Run a medieval kingdom for a year" | Economics (trade), History (governance), Math (taxation), Language (diplomacy) |
| "Design a sustainable city" | Engineering (infrastructure), Ecology (environment), Economics (budget), Art (aesthetics) |

Every complex quest pulls from multiple subjects, teaching students that knowledge isn't siloed — it's interconnected.
